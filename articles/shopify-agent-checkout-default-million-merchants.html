Shopify、AIエージェント経由の決済を100万事業者に自動有効化 オプトアウト方式へ転換

原題: Shopify Turns On Agent Checkout by Default for a Million Merchants

背景

Shopifyは2026年9月21日、Shop Payを通じたAIエージェント経由のチェックアウトを、米国の対象事業者向けに標準で有効化した。個別の連携を待つオプトイン方式から、初期設定でAIエージェントに開放するオプトアウト方式への転換であり、CEOのTobi Lütke氏が掲げる「すべてのShopifyストアをエージェント対応にする」戦略の一環である。

結論

  • 自動登録の対象事業者数は約100万に上り、変更したくない場合は管理画面から手動でオフに切り替える必要がある。
  • 2026年第1四半期、AI駆動のトラフィックは前年比8倍、AI検索由来の注文は前年比13倍に増加した。
  • 米消費者の23%（約6,100万人）が小売関連の調査をAIから始めており、AI経由の購買行動が一般化している。
  • 一方で対応できているのは小規模事業者の11%にとどまり、事業者の93%はAIエージェントが購入判断を誤った際の損失をAI提供企業側が負担すべきと考えている。
  • 発表後、Shopify株価は4〜7%上昇した。

メッセージ

プラットフォーム側が「事業者の同意を前提に待つ」姿勢から「原則対応済みとして進める」姿勢へ変わり始めている。自社が意識していないうちにAIエージェント経由の販売チャネルが既定で開いている可能性があり、商品データや在庫情報がAIに渡っても問題ない状態かを事前に確認しておく必要性を示す事例である。
